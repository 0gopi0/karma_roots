# Karma Roots

Home page for Karma Roots — *Ideas that grow, stories that stay.* Built with React + Tailwind CSS (v4) on Vite.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

- Copy lives in `src/data.js` (from the client's home page document). Set `CONTACT_EMAIL` there.
- Brand palette (plum & champagne) and fonts are defined in `src/index.css` under `@theme`.
- The lotus mark is redrawn as SVG in `src/components/Lotus.jsx`; the "karma" wordmark and founder portrait are in `src/assets/`.
